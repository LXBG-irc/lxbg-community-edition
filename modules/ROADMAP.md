# LXBG Module Roadmap

The manifests in this directory define the planned public module ecosystem. A manifest marked `roadmap` is compatibility metadata, not a claim that the module implementation is complete.

Current module families: Accounts & Login, WebChat, Profiles, Channel Admin, Channel Roles, AdServ, HelpServ, QuizServ and LXBG CAM/WebRTC.

Completed module source is added only after it has been separated from production configuration and checked for credentials/private data.
